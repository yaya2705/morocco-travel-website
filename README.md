# Morocco Travel Website

A responsive multi-page travel website showcasing Morocco's destinations, built with HTML, CSS and JavaScript for my UCL Web Technologies module.

## Pages

- **Home** – landing page introducing the site
- **Destinations** – overview of featured locations across Morocco
- **Moodboard** – visual inspiration and design references
- **Contact** – contact form with JavaScript-based interactivity
- **References** – sources and credits used in building the site

## Built with

- HTML5
- CSS3
- JavaScript
